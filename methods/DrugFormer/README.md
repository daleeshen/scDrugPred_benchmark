## Required DrugFormer Data

Before setting up the Docker environment or running the example, copy the DrugFormer `data/` directory from the downloaded `scDrugBenchmark_env` package into the GitHub repository.

The required source directory is:

```text
scDrugBenchmark_env/
└── DrugFormer/
    └── DrugFormer/
        └── data/
```

Copy this directory into:

```text
scDrugBenchmark_github/
└── methods/
    └── DrugFormer/
        └── DrugFormer/
```

For example:

```bash
cp -r scDrugBenchmark_env/DrugFormer/DrugFormer/data \
      scDrugBenchmark_github/methods/DrugFormer/DrugFormer/
```

After copying, the directory should contain:

```text
scDrugBenchmark_github/
└── methods/
    └── DrugFormer/
        └── DrugFormer/
            └── data/
```

The `scDrugBenchmark_env` package is available from Zenodo:

**Zenodo:** https://doi.org/10.5281/zenodo.23260161

## Prepare Example Inputs

From the `data/` directory, run:

```bash
Rscript prepare_drugformer_example.R
```

The prepared inputs are saved under:

```text
data/example/
├── balanced_1000/drugformer_input/
├── imbalanced_1_3/drugformer_input/
└── imbalanced_1_30/drugformer_input/
```

## Docker Environment

DrugFormer uses the shared Python Docker environment in `methods/shared_main_env/`.

Build the image from `methods/shared_main_env/`:

```bash
sudo docker build -t scdrugbenchmark-main .
```

Start the container from the `scDrugBenchmark` root directory:

```bash
sudo docker run --rm -it \
-v "$(pwd)":/workspace \
scdrugbenchmark-main
```

Inside the container, navigate to DrugFormer:

```bash
cd /workspace/methods/DrugFormer
```

Then follow the commands in the Run section below.

## Run the Example

From the `methods/DrugFormer/` directory, run:

```bash
PYTHON_EXEC=/path/to/python ./run_drugformer_example.sh
```

DrugFormer datasets generated by `Dataset_auto.py` are stored in:

```text
cell_dt/
```

Model checkpoints are saved to:

```text
example_output/
```

Run logs containing the evaluation results are saved to:

```text
example_logs/
```
