# scIDUC

scIDUC was evaluated through its official R Shiny web application, as a standalone source-code implementation was not available.

## Running scIDUC

For each benchmark dataset:

1. Upload the prepared expression matrix to the scIDUC web application.
2. Select the corresponding bulk RNA-seq reference dataset.
3. Select the target drug.
4. Run the prediction.
5. Download the prediction results for downstream evaluation.

The balanced and imbalanced benchmark datasets were evaluated using the same sampled cells as the other methods.
