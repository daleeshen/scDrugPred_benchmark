# ReSisTrace Lineage-Tracing Analysis

This folder contains the analysis code for the ReSisTrace lineage-tracing benchmark.

## Data

The pre-sensitive and pre-resistant Seurat object is provided in:

    scDrugBenchmark/data/lineage_tracing/ReSisTrace/

The object contains the cells from three independent sampling rounds merged into a single Seurat object.

The metadata also contains the prediction scores generated by the benchmarked methods.

## Analysis

Run the ReSisTrace analysis script from this folder:

    Rscript ReSisTrace_analysis.R

The script performs:

- benchmarking performance visualization across the evaluated methods
- UMAP visualization of the true pre-sensitive/pre-resistant labels
- UMAP visualization of prediction scores from each method
- differential expression analysis between pre-resistant and pre-sensitive cells
- Hallmark, KEGG, and GO-MF pathway enrichment analysis
- comparison between the intrinsic pre-resistant/pre-sensitive transcriptional signal and the conventional pre-treatment/post-treatment contrast

Please update the input, output, and GMT file paths in the R script before running it on a different system.

## Re-running model predictions

The provided Seurat object already contains the prediction results used in the analysis.

If independent prediction reproduction is required, the expression matrix and metadata can be exported from the Seurat object into the input format required by each method.

The corresponding models can then be re-run using the scripts provided under:

    scDrugBenchmark/methods/

The newly generated prediction scores can subsequently be added back to the Seurat metadata and analyzed using the same ReSisTrace analysis script.
