# Label Substitution Analysis

This folder contains scripts for the reciprocal label-substitution analysis between SCAD and scDEAL.

## Files

- `label_substitution.R`: prepares label-substituted input data.
- `scad.sh`: generates the original SCAD 5-fold splits.
- `replace_SCAD_fold_labels.py`: copies the original SCAD folds and replaces source-domain labels with scDEAL labels.
- `scdeal.sh`: runs scDEAL using the selected bulk-label file.

## Workflow

### 1. Prepare substituted labels

Run:

    Rscript label_substitution.R

This generates the inputs for:

- SCAD architecture + scDEAL labels
- scDEAL architecture + SCAD labels

For SCAD, the original SCAD workflow must first generate the corresponding `Source_exprs_resp_z.*.tsv` files. These expression files are reused and only the response labels are substituted.

### 2. Generate the original SCAD folds

Run:

    bash scad.sh

This generates the 5-fold stratified splits using the original SCAD labels.

### 3. Generate SCAD folds with scDEAL labels

Run:

    python replace_SCAD_fold_labels.py

The original SCAD folds are copied and only `Y_train_source.tsv` and `Y_val_source.tsv` are replaced with scDEAL labels. The feature matrices, cell order, and fold assignments remain unchanged.

The downstream SCAD training and prediction steps can then be run for both label conditions using the same model settings.

### 4. Run scDEAL

Run:

    bash scdeal.sh

The script reads the bulk labels from:

    /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.csv

For the original scDEAL-label condition, use the original label file.

For the SCAD-label condition, first back up the original file and replace it with the SCAD-labeled matrix generated by `label_substitution.R`:

    cp /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.csv \
       /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.backup.csv

    cp /media/shenli/Expansion/DRMREF/New_fig5/scDEAL_SCAD_label/ALL_label_binary_wf.csv \
       /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.csv

Then run the same `scdeal.sh` without changing model parameters.

After the substituted-label run, restore the original label file:

    cp /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.backup.csv \
       /media/shenli/Expansion/scDrug_benchmark/scDEAL/data/ALL_label_binary_wf.csv

## Experimental Design

The four model-label combinations are:

- SCAD architecture + SCAD labels
- SCAD architecture + scDEAL labels
- scDEAL architecture + scDEAL labels
- scDEAL architecture + SCAD labels

After all runs are completed, the prediction results are collected for downstream performance comparison, statistical analysis, and visualization.
